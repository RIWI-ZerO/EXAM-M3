This test covers the most important topics seen throughout Module 3. The topics covered were:

• Advanced DOM manipulation.
• Data persistence using Local Storage.
• API consumption with Fetch and promise handling.
• Creating dynamic routes in an SPA.
• User authentication and role management (admin and visitor).
• Use of json-server to simulate a database.
• Validations, error handling, and data consistency.
• Application of good programming practices in JavaScript projects.
